# ADR-003 — Validation organization

- **Date:** 2026-10-15
- **Status:** Integrated
- **Decision:** Tests are selected by changed owner via `OWNER_TEST_MATRIX.md`;
  not every script runs after every edit; mutation controls run only in isolated
  disposable copies; static, browser and device evidence are separate classes
  and never substitute for each other.
- **Context:** Measured profile durations in `TEST_CATALOG.md`; Tier 0–4/M/D
  definitions in `docs/AI_DEVELOPMENT_WORKFLOW.md`.
- **Consequences:**
  - Aggregate profiles: `quick`, `projects`, `tasks`, `workspace`, `reports`,
    `package5`, `closure`, `mutation:projects`.
  - `.validation/` is git-ignored; logs stay out of the repository.
  - Tier M runs only in disposable copies, sequentially, never against the
    served tree.
- **Canonical destination:** `docs/AI_DEVELOPMENT_WORKFLOW.md` (Validation
  Tiers); `docs/validation/OWNER_TEST_MATRIX.md`; `docs/validation/TEST_CATALOG.md`.
- **Supersedes:** none.
