# ADR-001 — Cline continuity model

- **Date:** 2026-10-15
- **Status:** Integrated
- **Decision:** Rules (`.cline/rules/`) define mandatory behavior; AI-state
  (`docs/ai-state/`) carries compact continuity; architecture carries durable
  truth; Skills only for proven repeatable procedures; MCP only for necessary
  external capabilities; Repomix secondary whenever repository access exists.
- **Context:** Repeated context loss across model switches made it necessary to
  rely on repository state files rather than conversation archaeology.
- **Consequences:**
  - Every new coding agent must read the six entry documents before working.
  - AI-state records what actually happened, never intent.
  - Repomix snapshots are not loaded when the repository is available.
- **Canonical destination:** `.cline/rules/00-markmapeditor-entrypoint.md`;
  `docs/ai-state/README.md`; `docs/AI_DEVELOPMENT_WORKFLOW.md` §30–§33.
- **Supersedes:** none (foundational decision).
