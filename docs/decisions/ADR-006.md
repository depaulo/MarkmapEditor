# ADR-006 — Consistency package scope and surface model

- **Date:** 2026-10-15
- **Status:** Integrated (PLAN-only)
- **Decision:** The Expanded-View Behavior and Visual Consistency package
  formalizes shared surface/navigation behavior (headers, Back/Workspace
  actions, source navigation, full-view entry/exit, route restoration,
  scroll/filter/draft retention, empty/failure states, responsive behavior)
  across Task Review, Task Board, Projects, Workspace Index, current Reports,
  and Notes/Knowledge navigation — without a generic expanded-view framework
  and without turning MarkmapEditor into a generic note/database app.
- **Context:** Owner staged brief §22; differentiation non-goals.
- **Consequences:**
  - Tasks remain Tasks, Projects remain Projects, Reports remain
    generation-oriented, Notes remain files.
  - No generic expanded-view framework, no WYSIWYG, no Standalone revival.
- **Canonical destination:** `docs/architecture/consistency-package-plan.md`
  (PLAN-only, Stage C); `NEXT_CYCLE_PLAN.md`.
- **Supersedes:** none.
