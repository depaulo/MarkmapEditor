# ADR-005 — Roadmap reorder: consistency before Reports

- **Date:** 2026-10-15
- **Status:** Integrated
- **Decision:** Package 5 closure → Expanded-View Behavior and Visual
  Consistency → Reports improvement → Draw.io/presentation-flow improvement →
  remaining 1.0 integration. Reports is delayed, not canceled; current Reports
  already works. Consistency must define shared surface/navigation behavior
  before Reports adds more presentation decisions.
- **Context:** Cohesive navigation has higher immediate product value.
- **Consequences:** Reports implementation is deferred, not canceled.
- **Canonical destination:** `NEXT_CYCLE_PLAN.md` §4 (package order after
  Package 5); product architecture §18.1.
- **Supersedes:** previous roadmap ordering that placed Reports before consistency.
